The top line is what was read, one letter per hold, with nothing changed. A dictionary word is suggested only when at least 3 letters were signed and at least 60 % of that word's letters match what was read (each within the model's top 3 for its hold); otherwise none is shown. The match allows one hold to be extra or missing. On the dataset clips a word is suggested about half the time and is right about 79 % of the time when it is; the dictionary has 54 words, so anything else can only appear in the top line. Measured leave-one-signer-out: 26 % per letter (40 classes, 10 % baseline). This build also includes two of the developer's own calibration sessions, which scored 100% on ا (alif) and ک (kaf) held out across sessions; that does not generalise to other letters or other people. Either hand is read the same way (the model uses joint angles and distances, which mirroring does not change), but every training signer used their right hand, so left-hand accuracy has not been measured.
